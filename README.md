# Air
## Project Description:
Air is a modern, responsive website with a clean and minimalist design. The project includes convenient navigation, smooth animations, and an interactive slider. The code is structured using the SCSS methodology for easy maintenance and scalability.

## Technologies Used:
- HTML – Semantic and accessible markup
- SCSS – Modular styles with mixins and variables
- JavaScript – Interactive slider

## Additional Instructions for Running the Project:
1. Install dependencies by running the following command in the terminal: `npm install`
2. To open the project in a browser, use the following command in the terminal: `npm start`

Alternatively, you can open the HTML file directly in a browser.
